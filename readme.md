# PetMatch — Plataforma de Adoção Responsável

# 1. Sobre o projeto

O PetMatch é uma plataforma desenvolvida com o objetivo de facilitar a divulgação de animais disponíveis para adoção e orientar pessoas interessadas em oferecer um lar responsável aos pets.

O projeto apresenta um catálogo de animais, páginas individuais com informações sobre cada pet, orientações sobre adoção consciente e um formulário ilustrativo para demonstrar o processo de interesse na adoção.

# 4. Estrutura do projeto

O projeto é composto por cinco páginas principais e algumas subpáginas:

- index.html: página inicial, apresentação da plataforma e animais em destaque.
- animais.html: catálogo de animais disponíveis para adoção.
- perfil.html: página de perfil de um animal, com informações detalhadas.
- adocao.html: apresentação das etapas e formulário ilustrativo de interesse na adoção.
- orientacoes.html: informações sobre guarda responsável e cuidados com os animais.

Também existem páginas individuais para apresentar os demais animais cadastrados.

- Exemplo: clove.html/chico.html/pigmeu.html/guaxas.html

# 5. Como executar o projeto

1. Baixe ou extraia os arquivos do projeto.
2. Abra a pasta PetMatch no Visual Studio Code.
3. Abra o arquivo `index.html` onde está situada a nossa página principal
4. Execute a página utilizando a extensão Live Server ou abra o arquivo diretamente em um navegador como Chrome, Firefox ou Opera.
5. Utilize o menu de navegação para acessar as demais páginas.
